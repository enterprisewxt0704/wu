# 参考资料说明

这个目录不参与 H1 软件运行，保留是为了：

1. **可追溯**：早期 `特征识别/` 对照实现、方案文档、报告生成脚本都还在，答辩被问“为什么选 M3”时可以翻。
2. **可复现报告**：`早期报告材料/` 里有早期 docx、课件/任务书文本、图、报告脚本；这些是历史材料，不是当前 H1 原型的一部分。
3. **避免误删**：不确认是否还有用的旧文件先放这里，而不是直接删除。

## 内容

| 目录 | 内容 |
|---|---|
| `特征识别/` | 早期 numpy+Pillow 特征工程 + 规则/质心/logreg/决策树对照实现，有独立 README 和 out 结果 |
| `早期报告材料/代码/` | `build_docx*.py`、`content_blocks.py`、`make_figures*.py`、`explore_*.py` 等报告/探索脚本 |
| `早期报告材料/资料/` | `task_docx.txt`、`task_xlsx.txt`、四讲知识点 docx、数据指标手册、`figs/`、`extracted/`、`build/` |
| `方案文档/` | `H1_方案_混合质检与操作界面.md`，最初的方案对比与确认记录 |

## 注意

- 这些脚本里的路径是整理前的旧路径（如 `out/`、`data/`、`.venv`），直接运行可能需要改路径；它们只用于查历史，不是交付程序。
- 当前 H1 原型的运行说明、接口、环境、报告/PPT/视频素材清单，都在 `H1原型/README.md` 和 `H1原型/文档/`。
